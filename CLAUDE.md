## Devbox inbox
- Files Eric drops for this repo arrive in `~/Devbox/Inbox/freeclass-stopstyleprofile/` (synced from his Dropbox).
- Only act on the inbox when Eric asks. Then: move each file to where it belongs in this repo,
  commit with a message naming the files, and leave the inbox empty.
- Files for Eric go in `~/Devbox/Outbox/`; they appear in his Dropbox within a minute or two.
- Never write anything else into ~/Devbox. Git is the only way code moves.

## No large media in the repo
- Never commit video, raw audio, large images or other big binaries (rule of thumb: over 5 MB).
- Keep them in Dropbox or storage and reference them by link or path instead.
